#### **1313. Input**
*   **뜻**: 입력, 투입
*   **발음**: **[인풋]** (/ˈɪnpʊt/)
*   **뉘앙스**:
    *   시스템에 넣는 정보입니다.
    *   의견이나 기여입니다.
*   **유의어**:
    *   **Entry**: 입력
    *   **Contribution**: 기여
    *   **Data**: 데이터
*   **📝 예문**
    > 1. User **input**. (사용자 입력.)
    > 2. **Input** data. (데이터 입력.)
    > 3. Need your **input**. (당신의 의견이 필요하다.)
    > 4. **Input** device. (입력 장치.)
